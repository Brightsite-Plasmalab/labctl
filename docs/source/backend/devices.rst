Devices
--------

.. currentmodule:: labctl.devices

Four different devices can currently be controlled by LabCTL:

- Pulse Generator (:class:`BncPdgCmds<BncPdgCmds>`)
- Setup translation stage (:class:`PiTranslationStage<PiTranslationStage>`)
- Thorlabs filter stage (:class:`ThorlabsStageCmds<ThorlabsStageCmds>`)
- Thorlabs rotation stage (:class:`ThorlabsRotationStageCmds<ThorlabsRotationStageCmds>`)

Links to the communication protocols:

- Pulse generator: `BNC Model 577 Pulse Delay Generator`_
- Setup translation stage: `Physik Instrumente translation stage (using the Mercury GCS command set)`_
- Thorlabs filter and rotation stage: `thorlabs translation stages`_

.. _BNC Model 577 Pulse Delay Generator: https://www.berkeleynucleonics.com/model-577
.. _Physik Instrumente translation stage (using the Mercury GCS command set): https://twiki.cern.ch/twiki/pub/ILCBDSColl/Phase2Preparations/Mercury_GCS_Commands_MS163E102.pdf
.. _thorlabs translation stages: https://www.thorlabs.com/newgrouppage9.cfm?objectgroup_id=9464
